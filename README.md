# AI Shopping Assistant

An LLM-powered Telegram shopping assistant built using n8n.

## Features
- Supports text and voice-based product search
- Uses Google Gemini for intelligent responses
- Uses Groq Whisper for speech-to-text conversion
- Fetches real-time Amazon product data
- Provides personalized shopping recommendations

## Tech Stack
- n8n
- Google Gemini
- Groq Whisper
- Telegram Bot API
- Amazon Scraper API

## Setup
Configure the required API credentials before running the workflow:
- GEMINI_API_KEY
- GROQ_API_KEY
- SCRAPER_API_KEY
- TELEGRAM_BOT_TOKEN
